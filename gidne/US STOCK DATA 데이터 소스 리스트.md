# US Stock Data 소스 명세서

기드네 프로젝트의 거시 경제 및 미국 주식 분석을 위한 데이터 소스들을 세분화하여 정리한 문서입니다.

## 1. 시장 지수 및 실시간 시세 (Market & Price Data)

지시한 대로 가장 빠르고 정확한 데이터를 수집하기 위한 핵심 소스들입니다.

| 분류 | 세부 항목 | 추천 소스 | 수집 방식 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| 주요 지수 | Nasdaq 100, S&P 500, Dow Jones | Polygon.io | Websocket | 개별 종목의 상대 강도 계산을 위한 기준점입니다. |
| 실시간 시세 | 개별 티커별 현재가 및 체결 내역 | Twelve Data | Websocket | 1분 미만의 초단기 변동성을 감지하기 위해 사용합니다. |
| 시간외 거래 | Pre-market 및 After-hours 데이터 | Finnhub | REST API | 장 개시 전후의 이상 급등락을 포착합니다. |

## 2. 거시 경제 및 유동성 지표 (Macro & Liquidity)

시장의 하락과 상승 추세를 결정짓는 매크로 환경 데이터입니다.

| 분류 | 세부 항목 | 추천 소스 | 수집 방식 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| 연준 자산 | WALCL (연준 총자산) | FRED | REST API | 시장에 풀린 전체 유동성의 규모를 파악합니다. |
| 재무부 현금 | TGA (재무부 일반계정), RRP (역레포) | FRED | REST API | 순유동성(Net Liquidity) 계산을 위한 필수 지표입니다. |
| 금리 및 채권 | 10년물/2년물 금리, 금리 역전폭 | Yahoo Finance | REST API | 장단기 금리차를 통해 경기 침체 시그널을 감지합니다. |
| 인플레이션 | CPI, PCE, 기대인플레이션율 | FRED | REST API | 연준의 금리 정책 방향을 예측하는 근거가 됩니다. |

## 3. 기업 실적 및 펀더멘털 (Earnings & Fundamentals)

개별 기업의 가치와 변동성 이벤트를 관리하기 위한 데이터입니다.

| 분류 | 세부 항목 | 추천 소스 | 수집 방식 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| 실적 발표 | 어닝 시즌 캘린더, EPS 예상치/실제치 | Earnings Whispers | Web Fetch | 실적 발표 직후의 주가 반응 및 변동성을 분석합니다. |
| 공시 데이터 | 10-K, 10-Q (SEC Filings) | SEC EDGAR | REST API | 기업의 재무 상태 및 리스크 요인을 심층 분석합니다. |
| 배당 정보 | 배당락일, 배당 수익률 | Alpha Vantage | REST API | 배당 재투자에 따른 복리 수익률 계산에 활용합니다. |

## 4. 시장 심리 및 수급 (Sentiment & Flow)

투자자들의 공포와 탐욕, 기관의 수급 흐름을 정량화합니다.

| 분류 | 세부 항목 | 추천 소스 | 수집 방식 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| 공포 지수 | VIX, MOVE Index, Skew Index | CBOE / Barchart | REST API | 시장의 하방 리스크 및 옵션 시장의 변동성을 측정합니다. |
| 심리 지표 | CNN Fear & Greed Index | CNN Business | Web Fetch | 대중의 투심이 극단적인 공포나 탐욕에 있는지 확인합니다. |
| 풋콜 비율 | Equity Put/Call Ratio | Options Clearing Corp | REST API | 시장 참여자들이 하락에 베팅하는 정도를 수치화합니다. |

## 5. 섹터 및 상대 강도 (Sector Alpha)

지수 대비 강한 종목을 찾기 위한 분석 데이터입니다.

| 분류 | 세부 항목 | 추천 소스 | 수집 방식 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| 섹터 맵 | 11개 섹터별 등락률 및 가중치 | Finviz | Web Fetch | 자금이 어느 섹터로 유입되고 있는지 시각화합니다. |
| 상대 강도 | RS Ratio, RS Momentum | 내부 연산 엔진 | Internal | 지수를 이기는 대장주를 필터링하는 기드네의 핵심 로직입니다. |

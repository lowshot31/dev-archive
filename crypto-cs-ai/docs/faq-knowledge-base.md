# 크립토 거래소 고객지원 FAQ 지식베이스

## 1. 입금 관련

### Q: 입금이 반영되지 않습니다.
블록체인 네트워크 컨펌 수에 따라 반영 시간이 다릅니다.
- BTC: 2 컨펌 (약 20분)
- ETH/ERC-20: 12 컨펌 (약 3분)
- BSC/BEP-20: 15 컨펌 (약 1분)
- SOL: 32 컨펌 (약 15초)
- XRP: 즉시 (단, 태그 누락 시 수동 처리 필요)
컨펌 완료 후에도 미반영 시 TX Hash와 함께 고객센터에 문의해 주세요.

### Q: 잘못된 네트워크로 입금했습니다. (오입금)
오입금 복구 가능 여부는 네트워크에 따라 다릅니다.
- **EVM 호환 체인 간 오입금** (ETH↔BSC↔Polygon↔Arbitrum): 복구 가능. 프라이빗 키 접근이 가능한 경우 동일 주소에서 해당 네트워크로 접속하여 자산을 회수할 수 있습니다. 거래소 지갑인 경우 기술팀 검토 후 복구 처리됩니다. 처리 기간: 영업일 기준 3~7일.
- **비EVM 체인으로 오입금** (SOL, XRP, ATOM 등): 복구 불가능한 경우가 대부분입니다. 해당 체인의 주소 체계가 다르기 때문입니다.
- **메모/태그 누락 입금** (XRP, XLM, ATOM, EOS): 복구 가능. TX Hash와 보낸 주소를 고객센터에 전달해 주시면 수동 반영 처리됩니다. 처리 기간: 영업일 기준 1~3일.

### Q: 최소 입금 금액이 있나요?
네, 각 코인별 최소 입금 금액이 있습니다. 최소 금액 미만 입금 시 잔고에 반영되지 않으며 복구가 불가능합니다.
- BTC: 0.0001 BTC
- ETH: 0.001 ETH
- USDT (ERC-20): 1 USDT
- USDT (TRC-20): 1 USDT

## 2. 출금 관련

### Q: 출금 신청 후 처리가 지연됩니다.
출금은 보안 검증 절차를 거칩니다.
- **소액 출금** (100만원 미만): 자동 처리, 네트워크 상황에 따라 5~30분
- **대액 출금** (100만원 이상): 수동 검토, 영업일 기준 1~2시간
- **고액 출금** (5000만원 이상): AML(자금세탁방지) 검토, 영업일 기준 1~3일
출금 지연이 24시간 이상 지속될 경우 고객센터로 문의해 주세요.

### Q: 출금 주소를 잘못 입력했습니다.
블록체인 특성상 이미 전송된 트랜잭션은 취소가 불가능합니다. 잘못된 주소가 실존하는 주소인 경우 자산 복구가 불가능합니다. 출금 전 반드시 주소를 재확인해 주세요.

### Q: 출금 한도는 어떻게 되나요?
인증 레벨에 따라 다릅니다.
- Level 1 (이메일 인증): 일 100만원
- Level 2 (본인인증 완료): 일 5000만원
- Level 3 (추가 서류 제출): 일 10억원

## 3. 거래 관련

### Q: 주문이 체결되지 않습니다.
지정가 주문의 경우 시장 가격이 지정 가격에 도달해야 체결됩니다. 시장가 주문을 사용하시면 즉시 체결됩니다. 단, 유동성이 낮은 코인의 경우 슬리피지가 발생할 수 있습니다.

### Q: 수수료 체계가 어떻게 되나요?
- **현물 거래**: Maker 0.1%, Taker 0.2%
- **VIP 등급별 할인**: 30일 거래량 기준 최대 50% 할인
- **코인 결제 할인**: 거래소 자체 토큰으로 수수료 결제 시 25% 추가 할인

## 4. 계정/보안

### Q: 2FA(2단계 인증)를 분실했습니다.
본인 확인 절차를 통해 2FA를 초기화할 수 있습니다.
필요 서류: 신분증 사진, 셀피(신분증 들고 촬영), 가입 이메일에서 보낸 초기화 요청 메일.
처리 기간: 영업일 기준 1~3일. 보안을 위해 초기화 후 24시간 출금이 제한됩니다.

### Q: 계정이 잠겼습니다.
비밀번호 5회 이상 오입력 시 계정이 자동으로 잠깁니다.
- 30분 후 자동 해제
- 즉시 해제를 원하시면 등록된 이메일로 비밀번호 재설정을 진행해 주세요.

### Q: 해킹이 의심됩니다.
즉시 고객센터에 연락하여 계정 동결을 요청해 주세요. 24시간 긴급 대응 채널: security@exchange.com
조치 순서: 1) 계정 동결 2) 비밀번호 변경 3) 2FA 재설정 4) API 키 전체 삭제 5) 접속 기록 확인

## 5. KYC/AML

### Q: KYC 인증이 거부되었습니다.
거부 사유를 확인하고 재제출해 주세요. 일반적인 거부 사유:
- 신분증 사진이 흐릿함
- 셀피에서 얼굴이 가려짐
- 서류 유효기간 만료
- 이름 불일치 (영문/한글)
재제출은 즉시 가능하며, 재심사는 영업일 기준 1~2일 소요됩니다.

### Q: 해외 거주자도 이용 가능한가요?
FATF 고위험 국가 거주자는 서비스 이용이 제한됩니다. 그 외 해외 거주 한국인은 KYC Level 2 인증 완료 시 이용 가능합니다.

## 6. API 관련

### Q: API Rate Limit에 걸렸습니다.
API 호출 제한: 초당 10회, 분당 300회. 제한 초과 시 429 에러가 반환됩니다. WebSocket을 활용하면 실시간 데이터를 효율적으로 수신할 수 있습니다.

### Q: API 키 권한 설정은 어떻게 하나요?
- Read: 잔고 조회, 주문 내역 조회
- Trade: 주문 생성/취소
- Withdraw: 출금 (IP Whitelist 필수)
보안을 위해 필요한 최소 권한만 부여하시고, 반드시 IP Whitelist를 설정해 주세요.
